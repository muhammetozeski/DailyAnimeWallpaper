# DailyAnimeWallpaper
Put the exe to startup folder. You will get different anime wallpapers every time program run.

This program gets wallpapers from https://waifu.pics
Thanks to this repository https://github.com/Waifu-pics/waifu-api

Downloaded images are saved in `UserCache/Pictures` beside the executable.

The executables are digitally signed. To let Windows verify the signature, run `Install-Certificate.cmd` from `SignatureTrust.zip` once. The programs run without it; only the signature stays unverified.
