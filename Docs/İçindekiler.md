# DailyAnimeWallpaper Dokümantasyonu

Bu fihrist, `DailyAnimeWallpaper` geliştirilirken ve API kaynakları güncellenirken ihtiyaç duyulan doğrulanmış proje bilgisinin giriş noktasıdır.

## Temel rehberler

- [Dokümantasyon-Neden-Önemli.md](Dokümantasyon-Neden-Önemli.md): Proje bilgisinin neden korunduğunu, tekrar araştırmayı nasıl önlediğini ve bakım ilkelerini anlamak için okunur.
- [Dokümantasyon-Nasıl-Yapılır.md](Dokümantasyon-Nasıl-Yapılır.md): Yeni konu eklerken, mevcut belgeyi güncellerken ve doğrulama sınırlarını yazarken uygulanır.

## Konular

- [Kaynak-Katalogu-Ve-Yanit-Bicimleri.md](Kaynak-Katalogu-Ve-Yanit-Bicimleri.md): Yerleşik veya özel anime API kaynakları eklerken, booru/JSON/direkt görsel yanıt farklarını ve canlı testlerde doğrulanmış sunucu davranışlarını öğrenmek için okunur.
