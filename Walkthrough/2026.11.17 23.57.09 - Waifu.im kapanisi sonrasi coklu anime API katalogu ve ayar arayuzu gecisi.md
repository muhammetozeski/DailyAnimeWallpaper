# Waifu.im kapanışı sonrası çoklu anime API kataloğu ve ayar arayüzü geçişi

## Güncel çerçeve

`DailyAnimeWallpaper` (`net10.0-windows`, C# 14, WinForms + konsol girişli taşınabilir Windows uygulaması, sürüm `2.0.0`) argümansız çalıştırıldığında etkin anime API kaynaklarından `UInt128` ağırlıklı kriptografik rastgele seçimle duvar kağıdı indirip masaüstüne uygular ve kapanır; `settings` argümanıyla çalıştırıldığında API/iç tür ağacını, ağırlıkları (`0..int.MaxValue`), özel kaynakları ve NSFW filtresini yöneten WinForms penceresini açar. Kullanıcı ayarları `UserData/settings.txt`, düzenlenebilir API kataloğu `UserData/sources.json`, indirilen görseller varsayılan olarak `Pictures/`, loglar `AppCache/Logs/` altındadır.

## Olay ve tecrübe

Önceki sürümün tek kaynağı olan `https://api.waifu.im/images` servisinin 24 Ekim 2026 itibarıyla kalıcı olarak kapandığı ve `api.waifu.pics` alan adının da düştüğü doğrulandı. Elli beşten fazla aday kaynak `.NET HttpClient` ile canlı test edilerek Cloudflare 403/401 engelli veya bozuk yanıtlı servisler elendi; yalnızca anime/waifu/booru/ACG görseli döndüren 27 çalışan API ve 165 iç tür (NSFW türler varsayılan kapalı) `BuiltInCatalog` içine alındı. Canlı testlerde `Pic.re` yanıtlarının `https://` öneksiz dönebildiği, `Safebooru.org` ve `TBIB` DAPI uç noktalarının rastgele sıra yerine `pid` sayfalaması gerektirdiği ve DNS `HostNotFound` hatalarında Polly tekrarı yapmamanın yedek kaynağa geçişi hızlandırdığı görülüp `WallpaperClient` içinde uygulandı. Ayrıntılar [Kaynak-Katalogu-Ve-Yanit-Bicimleri.md](../Docs/Kaynak-Katalogu-Ve-Yanit-Bicimleri.md) belgesindedir.

## Devam için anlamı

- Yeni yerleşik kaynak eklemeden önce tarayıcıda açılmasına güvenme; `.NET HttpClient` (`AppConstants.UserAgent`) ile doğrudan yanıt ve ikili görsel indirme testi yap.
- Win32 çağrıları `NativeMethods.txt` + `Microsoft.Windows.CsWin32` üzerinden üretilir; elle `DllImport` ekleme.
- `Strings.cs` içine eklenen her metin anahtarını aynı yer tutucularla `Localization/lang.en.xml` içine de ekle; `ApplicationServices.Initialize()` açılışta iki dil dosyasının tam eşleşmesini zorunlu tutar.
